Dossier d'Étude & Choix

Mes choix d'installation et réponses aux questions

Pour répondre aux exigences de performance du projet, voici les choix techniques que j'ai retenus pour la configuration de la machine virtuelle :

  • 1. Système d'exploitation : Ubuntu Server
    Mon choix s'est porté sur la version "Server" (dépourvue d'interface graphique). Cette version permet d'optimiser les ressources système et de se rapprocher des conditions réelles d'administration en entreprise (gestion stricte en ligne de commande).
  • 2. Processeurs : 4 CPU
    J'ai augmenté la configuration par défaut pour allouer 4 processeurs virtuels. Cette puissance de calcul supplémentaire garantit l'absence de latence lors de l'exécution de tâches simultanées (installation de paquets, compilation) et assure une réactivité optimale du serveur.
  • 3. Mémoire RAM : 8192 Mo (8 Go)
    J'ai défini une allocation confortable de 8 Go de mémoire vive. Ce dimensionnement permet de prévenir tout recours à la mémoire Swap (plus lente) et assure une fluidité parfaite des services, même en cas de forte sollicitation du serveur Apache.
  • 4. Stockage : Disque VDI Dynamique (45 Go)
    L'allocation dynamique a été privilégiée par rapport à la taille fixe. Ce choix technique permet d'économiser l'espace disque de l'hôte, car le fichier de la VM n'occupe que l'espace réellement utilisé par les données du système, sans réserver inutilement 45 Go.
  • 5. Réseau : Accès par Pont (Bridge)
    Le mode "Accès par Pont" a été sélectionné impérativement. Contrairement au mode NAT qui isole la VM, ce mode lui permet d'obtenir sa propre adresse IP sur le réseau local, la rendant ainsi directement accessible depuis le navigateur de l'ordinateur hôte.

Création de l'utilisateur

Pour la sécurité, il ne faut jamais travailler en tant que "root" (le super-administrateur). J'ai donc créé un utilisateur standard avec mon nom de groupe pour administrer le serveur proprement (via la commande sudo).

Couleurs du Terminal

J'ai modifié le fichier .bashrc pour ajouter de la couleur à l'invite de commande. C'est pratique pour identifier immédiatement qui est connecté et cela rend le terminal plus lisible et agréable.

Logiciel installé : Apache2.

À quoi ça sert ?

Apache est le serveur HTTP le plus utilisé. C'est le logiciel qui écoute les requêtes sur le port 80 et renvoie mes fichiers HTML. Je l'ai installé et activé avec la commande apt install apache2.

Mes actions :
  • Mode Pont (Bridge) : Comme expliqué précédemment, ce réglage permet à la VM d'être accessible sur le réseau local, simulant ainsi un serveur physique.
  • Changer les droits (Chown) : Par défaut, le dossier /var/www/html appartient à root. J'ai utilisé la commande chown pour m'attribuer la propriété du dossier et pouvoir modifier les fichiers sans erreur de permission.

Outil utilisé : WebStorm sur Windows.

Pourquoi ?

L'édition de code directement dans le terminal Linux étant fastidieuse, j'ai configuré une connexion SFTP sur WebStorm. Cela me permet de développer confortablement sur Windows et de synchroniser les fichiers instantanément sur le serveur.

  • 1. Définition de la virtualisation :
    C'est une technologie permettant de créer des versions virtuelles de ressources informatiques (ordinateur, stockage). Elle permet de faire fonctionner plusieurs systèmes d'exploitation (comme Ubuntu) sur une seule machine physique hôte, en partageant les ressources matérielles.
  • 2. Différence Émulateur vs Virtualisation :
    Un émulateur imite le matériel de façon logicielle (traduction d'instructions), ce qui est lent. La virtualisation utilise directement le processeur physique grâce à l'hyperviseur, offrant des performances quasi-natives.
  • 3. Type de virtualisation (VirtualBox) :
    VirtualBox est un hyperviseur de Type 2 (Hosted). Il s'installe comme une application classique sur un système d'exploitation existant (Windows). À l'inverse, un hyperviseur de Type 1 (Bare-metal) s'installerait directement sur le matériel sans OS intermédiaire.
  • 4. Où est sauvegardée la VM ?
    La machine virtuelle est stockée localement sur mon disque dur physique, généralement dans le dossier utilisateur. Elle se compose de fichiers de configuration (.vbox) et de disque virtuel (.vdi).

Dossier d'Étude & Choix

Justification de l'installation et réponses théoriques

Configuration : Ubuntu Server 24.04 (64-bit).

Pourquoi ces choix ?

Nous avons alloué 4 Processeurs et 8 Go de RAM. C'est plus que le minimum requis, mais cela garantit que la VM ne ralentit jamais lors de l'installation des paquets.
Pour le stockage, j'ai prévu 45 Go : Ubuntu en prend environ 10, le reste est dédié au site web et offre une marge de sécurité confortable pour les logs et les mises à jour système.

Création de l'utilisateur

Explication : C'est dangereux pour la sécurité de rester connecté en "root" tout le temps. Nous avons donc créé un utilisateur standard avec le nom imposé (`trinomeXX`) pour travailler proprement.

Couleurs du Terminal

Explication : Nous avons modifié le fichier .bashrc pour mettre de la couleur. C'est plus pratique pour voir tout de suite si on est en utilisateur simple ou en admin, et ça évite les erreurs.

Logiciel installé : Apache2.

A quoi ça sert ?

C'est le logiciel principal du projet. Il transforme ma machine virtuelle en un vrai serveur web capable d'afficher nos pages HTML. Il a été installé simplement avec la commande apt install.

Nos actions :
  • Mode Pont (Bridge) : Activé pour que la VM ait une vraie adresse IP sur le réseau local. C'est ce qui permet à Windows de communiquer avec elle.
  • Commande Chown : De base, le dossier du site appartient à root. Nous avons dû changer le propriétaire (avec chown) pour avoir le droit de modifier les fichiers HTML.

Outil utilisé : WebStorm (Windows).

Pourquoi ?

Coder directement dans le terminal noir de Linux, c'est compliqué. Nous avons configuré une connexion SFTP pour pouvoir coder confortablement sur Windows et envoyer les fichiers automatiquement sur le serveur.

  • 1. Définition de la virtualisation :
    La virtualisation est une technologie qui permet de créer des versions virtuelles d'une ressource informatique (ordinateur, stockage) à partir d'une seule machine physique. Cela nous a permis d'installer Ubuntu sans toucher à notre Windows principal.
  • 2. Différence Émulateur vs Virtualisation :
    Un émulateur imite tout le matériel de façon logicielle (c'est lent). La virtualisation utilise directement la puissance réelle du processeur (c'est rapide et performant).
  • 3. Type de virtualisation (VirtualBox) :
    VirtualBox est un hyperviseur de Type 2 (Hosted). Il s'installe comme une application classique sur notre système d'exploitation hôte (Windows), contrairement aux hyperviseurs de Type 1 (Bare-metal) qui s'installent directement sur le matériel.
  • 4. Sauvegarde de la VM :
    La machine virtuelle est stockée sous forme de fichiers (principalement un disque virtuel .vdi). Ces fichiers sont sauvegardés localement sur le disque dur de l'ordinateur hôte (dans le dossier Utilisateur de Windows).
